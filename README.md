# Arabic-GED-Ghala

Arabic banking intent classification project using machine learning and deep learning techniques.

## Project Overview

This repository contains work related to Arabic banking intent classification.  
The goal is to classify Arabic banking-related user queries into different intent categories.

The project includes notebooks, dataset files, and a project report.

## Original Paper

This project replicates and experiments with the paper:

**ArBanking77: Intent Detection Neural Model and a New Dataset in Modern and Dialectical Arabic**  
by Mustafa Jarrar, Ahmet Birim, Mohammed Khalilia, Mustafa Erden, and Sana Ghanem.

The original paper introduces **ArBanking77**, an Arabic banking intent detection dataset based on the English Banking77 dataset. It contains **31,404 Arabic queries** across **77 banking intents**, covering both **Modern Standard Arabic (MSA)** and **Palestinian dialect**.

The paper fine-tunes AraBERT-based models for Arabic banking intent classification and reports strong performance, with an F1-score of **0.9209** for MSA and **0.8995** for Palestinian dialect.

Our project is based on replicating the intent classification task and experimenting with Arabic banking text classification using machine learning and deep learning methods.
